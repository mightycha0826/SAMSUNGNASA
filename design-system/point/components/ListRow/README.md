# ListRow

아이콘 원 · 이름 · 둘째 줄 · 오른쪽 값으로 된 목록 줄. 높이 64px(대화 목록처럼 얼굴이 크면 72px).

- 아이콘 원은 44px `row` 면에 `primary-icon` 아이콘.
- 이름 16px 550, 둘째 줄 13px `ink-muted`, 값 16px 600 `tabular-nums`.
- 값을 강조할 일이 있으면(들어온 돈) `pt-item__value--point`. 한 화면에 몇 개 안 될 때만.
- 묶음 머리는 `pt-section`: 왼쪽 이름(600), 오른쪽 합계.
- 누르면 0.99, 목록 줄은 거의 안 줄어들어요.
