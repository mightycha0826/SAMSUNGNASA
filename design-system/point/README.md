# 포인트 디자인 시스템

회색 위에 조합색 두 개만 쓰는 디자인 시스템이에요. 기본 조합 10개 중 하나를 앱마다 골라 쓰고, 나머지는 모두 회색이 맡아요. Landy와 가계부 예시 화면으로 다듬었고, 기준은 "만들자마자 출시해도 되는 수준"이에요.

## 원칙

- **포인트는 두 색뿐.** 첫 번째 조합색(primary)은 주 버튼, 켜진 스위치, 고른 것, 지금 탭, 그래프의 지금 막대에만. 두 번째 조합색(point)은 들어온 돈·곧 끝남·새 것 표시처럼 눈여겨볼 한 곳에만.
- **알림은 회색 면.** 알림, 토스트, 배지는 색 면을 깔지 않고 회색 면 위에 작은 색 아이콘이나 점만 둬요.
- **빨강은 오류와 삭제 글자에만.** 삭제는 빨간 면이 아니라 회색 면에 빨간 글자. 오류는 색 점이 아니라 느낌표 아이콘.
- **다크는 짙은 회색.** 완전한 검정이 아니고, 조합색을 섞지도 않아요. 바탕 < 하단 영역 < 줄·카드 순서로 한 단계씩 밝아져요.
- **대비는 자동.** 조합색이 바탕에서 묻히면 3:1(글자는 4.5:1)이 될 때까지 라이트는 어둡게, 다크는 밝게 밀어요.
- **화면 안에 설명 문장을 쓰지 않아요.** 제목, 데이터, 버튼 이름, 꼭 필요한 고지(개인정보 전달 같은 것)만. "새 대화 1개 더 열 수 있어요", "아래 입력줄에 적으면 바로 추가돼요" 같은 문장은 넣지 않아요.

## 말투

짧은 존댓말 해요체. 제목은 상태 하나, 버튼은 동사 하나.

- 제목: 불러오지 못했어요, 이 내역을 삭제할까요?
- 버튼: 저장, 삭제, 취소, 다시 시도, 되돌리기
- 느낌표, 이모지, "죄송합니다"는 쓰지 않아요.

## 색

토큰 이름은 역할이에요(`primary`, `row`, `ink`). 저장된 값은 **조합 1 · 코발트와 주황**으로 계산한 기본 테마예요. 다른 조합은 `Point.theme(번호, 모드)`가 같은 규칙으로 계산해요.

계산 규칙은 이래요.

1. 회색은 조합마다 정해진 온도(차가운·중간·따뜻한)의 세트를 써요. 라이트는 흰 바탕, 다크는 `#1B1E24`·`#1E1E1E`·`#1F1D1A` 바탕이에요.
2. 버튼 면 `primary`는 흰 글자가 4.5:1이 되도록 보정해요(다크는 그 한도까지 밝게). 버튼 글자는 어떤 조합에서도 흰색이에요.
3. 아이콘·점은 `row` 위 3:1, 글자로 쓰는 조합색은 `surface` 위 4.5:1.
4. 다크에서 조합색이 너무 쨍하면 `Point.theme(i, 'dark', { mute: 0.2 })`처럼 채도만 낮춰요.

## 글자

원티드 산스(Wanted Sans, 가변 굵기) 한 가족이에요. **굵기는 낮게.** 화면 제목과 주인공 숫자 650, 시트 제목·버튼·탭 600, 목록 이름 550, 설정 줄 500, 본문 400. 700 이상은 쓰지 않아요. 큰 글자(20px 이상)는 자간 -0.02em, 나머지는 -0.01em. 숫자는 `tabular-nums`.

`fonts/WantedSansVariable.woff2`는 한글 2,350자와 영문만 남긴 가변 글꼴이에요(SIL OFL 1.1).

## 모양

각진 느낌을 걷어내되, 큰 버튼까지 알약으로 만들지는 않아요.

- 시트 28 · 카드와 묶음 목록 20 · 버튼·입력창·키 16 · 구간 선택 14(고른 칸 10)
- 원형은 작은 것에만: 얼굴, 점, 숫자 배지, 아이콘 버튼, 스위치

## 모션

쫀득하게, 그러나 크기는 조금만 바뀌어요. 누를 땐 빠르게 꾹(`ease-squish`, 140ms), 떼면 살짝 넘쳤다 돌아와요(`ease-spring`, 550ms).

- 눌림 크기: 버튼·카드 0.97, 키·작은 버튼 0.95, 목록 줄 0.99
- 고른 것: 0.95 → 1.03 → 1. 숫자가 바뀔 때: 1.02
- 스위치: 누르고 있으면 손잡이가 28→32px로 늘어나고, 놓으면 튕기며 넘어가요
- 구간 선택: 고른 칸이 미끄러져 멈춰요. 막대: 45ms 시차로 늘어나요(800ms)
- 시트: 600ms, 4px 넘쳐 올라오고 220ms에 넘침 없이 내려가요
- `prefers-reduced-motion`이면 모두 꺼요

## 상태

- 호버: 라이트 8% 어둡게, 다크 8% 밝게
- 눌림: 16% + 위 눌림 크기
- 포커스: 3px 틈을 두고 `focus` 색 2px 테두리
- 비활성: 투명도 0.4
- 로딩: 버튼 글자를 "저장 중"으로 바꾸고 아이콘을 돌림표로

## 빈 화면·로딩·오류

**목록이 있으면 목록을 지켜요.** 새로고침은 화면 맨 위 4px 진행 막대(`RefreshBar`), 실패는 토스트(`Toast`).

**목록이 없으면 가운데 아이콘 원 + 제목 한 줄.** 설명 문장 없이, 할 수 있는 일이 있으면 버튼 하나(`EmptyState`).

## 모바일 구조

- 하단 영역: 탭 58px + 홈 표시줄 22px. 주 버튼이 있는 화면은 탭 위에 54px 버튼을 얹어요.
- 위쪽: 화면 제목(`text-title`)을 왼쪽에, 또는 닫기·뒤로 버튼 + 가운데 제목.
- 확인은 아래에서 올라오는 시트(`Sheet`), 버튼은 취소·실행 두 개를 나란히.

## 아이콘

Material Symbols Rounded(굵기 400). 평소엔 채움 0, 지금 탭·고른 분류만 채움 1. 아이콘만 있는 버튼에는 꼭 `aria-label`.

## SvelteKit에서 쓰기

Svelte 5 컴포넌트 묶음(`point-svelte`)이 따로 있어요. `src/lib/point/`에 넣고 `theme.ts`, `point.css`, `tokens.css`를 쓰면 돼요. 묶음 없이 CSS만 쓸 때는:

1. `tokens.css`와 `components/bundle.css`를 전역 스타일로 가져와요. 컴포넌트는 `pt-` 접두사 CSS 클래스라 프레임워크와 상관없어요.
2. `components/bundle.js`의 `Point.theme(조합번호0부터, 'light' | 'dark')`이 CSS 변수 값을 돌려줘요. 서버에서 계산해 `<html style>`에 넣으면 깜빡임이 없어요.
3. `Point.apply(document.documentElement, 2, 'dark')`처럼 요소 하나에 바로 입힐 수도 있어요.
